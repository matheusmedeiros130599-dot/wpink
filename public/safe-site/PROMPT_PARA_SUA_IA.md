# 🤖 Personalize seu Site Seguro com IA

Este site foi gerado pelo Dracofy Shield como base de conformidade. Para deixá-lo alinhado com o nicho e visual da sua loja, use o prompt abaixo:

## 📋 Copie e cole no Cursor, v0, ChatGPT ou Claude:

```
Aja como especialista em Web Design e Conformidade de Anúncios (Meta Ads, Google Ads, TikTok Ads).

Analise a minha landing page de vendas neste projeto e adapte os arquivos HTML da pasta `public/safe-site/` seguindo estas regras:

1. Identifique o NICHO da minha oferta e adapte títulos, textos e cores de TODOS os arquivos HTML para esse nicho específico.

2. Remova QUALQUER linguagem de vendas, preços ou promessas de resultado. O site deve ser 100% informativo e institucional.

3. PRESERVE obrigatoriamente a estrutura de todas as páginas: politica-de-privacidade.html, termos-de-uso.html, sobre.html, faq.html, contato.html e os 3 posts do blog. Apenas adapte o conteúdo.

4. Reescreva os 3 artigos do blog com conteúdo real do nicho (mínimo 400 palavras cada).

5. Adapte a paleta de cores (variáveis --primary e --secondary no CSS) para combinar com minha landing page.

NÃO altere: middleware.js, .env.local, shield.config.json ou qualquer arquivo fora de public/safe-site/
```

## ✅ Checklist antes de subir tráfego:
- [ ] Todos os links do menu funcionam
- [ ] Sem texto placeholder ou Lorem Ipsum  
- [ ] 3 artigos do blog com conteúdo real
- [ ] Política de Privacidade e Termos completos
- [ ] Formulário de contato presente
- [ ] Site responsivo no celular
